# Commandes git utiles

## Guide rapide Git

Vérifier la branche actuelle :

`git branch`

Passer à config-feature :
`git checkout config-feature`

Créer une nouvelle branche depuis config-feature :

`git checkout -b nouvelle-feature`

Sauvegarder les modifications :

`git add .`

`git commit -m "Message du commit"`

`git push origin <nom-branche>`

Fusionner dans main (après tests) :

`git checkout main`

`git merge config-feature`

`git push origin main`
